# fitsync-legal (redirección)

Solo redirige las URLs antiguas `ulizarralde-fitsync.github.io/fitsync-legal/…`
a https://trenzia.es. La web de verdad está en `ulizarralde-FitSync/trenzia-web`
(que se llamaba así, `fitsync-legal`, hasta el 27/09/2026).

Existe porque los builds de la app hasta el 22 enlazan la política de privacidad
y la página de eliminar cuenta con esas URLs, que dieron 404 al renombrar el
repo. Se puede borrar cuando no quede ningún build viejo en uso ni ninguna ficha
de tienda que las declare.
